# Attention Matters

Vercel-ready Next.js site for [attentionmatters.ai](https://attentionmatters.ai).

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Pre-launch configuration

1. Create the Attention Matters mailbox.
2. Inquiry messages are addressed to `irenebuildsai@gmail.com` through `CONTACT_EMAIL` in `app/components/inquiry-form.tsx`.
3. Confirm the Irene Builds AI Instagram handle in `app/page.tsx`.
4. Import this repository into Vercel.
5. Add `attentionmatters.ai` and `www.attentionmatters.ai` in the Vercel project domain settings.
6. Update Cloudflare DNS to the records Vercel provides, after the Vercel deployment is verified.

The launch inquiry form intentionally opens the visitor's email client. It does not collect or store personal information. A server-backed form can be added once the mailbox and preferred email provider are ready.
